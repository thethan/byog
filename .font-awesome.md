- **License:** Pro

- **CDN URL:** `https://kit.fontawesome.com/75b1a963e0.js`

## Defaults

- **Style:** solid
- **Family:** classic

## Import Pattern

Icons use class-based `<i>` elements. Dynamic token icons store the complete class string, such as `fa-solid fa-heart`.

## Conventions

- The main frontend is vanilla JavaScript and HTML under `web/`.
- Token icons are created by `createTokenPool()` in `web/app.js`.
- Life displays its current total as text beside the Font Awesome heart icon.
